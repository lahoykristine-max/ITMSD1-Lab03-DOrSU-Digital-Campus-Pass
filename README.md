# ITMSD1-Lab03-DOrSU-Digital-Campus-Pass

## Laboratory Exercise 03: React Native Fundamentals

A React Native mobile application developed for ITMSD 1 — Fundamentals of Mobile Design and Tools.

The application demonstrates React Native components, TypeScript props, state management, and Flexbox styling through a DOrSU Digital Campus Pass.

## Features

- Student Digital Campus Pass
- Student information card
- Active/Inactive pass status
- Campus gate scan counter
- Reset scan counter
- Pass Active toggle
- React Native Flexbox layout

## Technologies Used

- React Native
- Expo SDK 57
- React 19
- TypeScript
- VS Code
